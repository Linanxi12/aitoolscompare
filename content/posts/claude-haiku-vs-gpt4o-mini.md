## 3 Key Tests

### Test 1: Reasoning
**Claude Haiku:** Inherits Opus 4's careful reasoning pattern — structured, accurate, admits uncertainty. **GPT-4o mini:** Faster, broader, but more confidently wrong on edge cases. Haiku's reasoning feels like "junior Claude"; GPT-4o mini feels like "faster, slightly less accurate GPT-4o."

<div class="verdict-box"><div class="verdict-label">📝 Verdict</div><p class="verdict-text"><strong>Claude Haiku — sharper reasoning, fewer confident errors.</strong></p></div>

### Test 2: Accessibility
**GPT-4o mini:** The default free model in ChatGPT Free — 300M+ weekly users. No switching tools needed. Also available via API at extremely low cost. **Claude Haiku:** Available via Claude.ai free tier and API. Smaller user base, less brand recognition.

<div class="verdict-box"><div class="verdict-label">📝 Verdict</div><p class="verdict-text"><strong>GPT-4o mini — ubiquity and ChatGPT platform integration.</strong></p></div>

### Test 3: Speed and Cost
Both are fast (~100-150 tok/s) and extremely cheap via API. **Claude Haiku:** $0.25/M input, $1.25/M output. **GPT-4o mini:** $0.15/M input, $0.60/M output. GPT-4o mini is ~2× cheaper via API. Both are suitable for high-volume, cost-sensitive applications.

<div class="verdict-box"><div class="verdict-label">📝 Verdict</div><p class="verdict-text"><strong>Near draw — both fast and cheap; GPT-4o mini slightly cheaper via API.</strong></p></div>
