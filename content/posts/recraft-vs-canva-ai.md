## 3 Key Tests

### Test 1: Vector Generation
**Task:** Generate a logo icon from text prompt. **Recraft:** Generated an editable SVG — clean paths, proper layers, scalable to any size. Imported directly into Figma/Illustrator for further editing. Unique among AI design tools. **Canva AI:** Generates raster images (PNG) from prompts — good quality, non-editable as vectors.

<div class="verdict-box"><div class="verdict-label">📝 Verdict</div><p class="verdict-text"><strong>Recraft — vector/SVG generation is a unique, unmatched capability.</strong></p></div>

### Test 2: Template-Driven Design
**Task:** Create a social media graphic in 5 minutes. **Canva AI:** 1M+ templates → select → customize colors/text → done in 3 minutes. Magic Design generates full layouts from a brief. **Recraft:** Better quality output, but no template library — requires more design knowledge and time.

<div class="verdict-box"><div class="verdict-label">📝 Verdict</div><p class="verdict-text"><strong>Canva AI — templates + Magic Design = fastest path to polished output.</strong></p></div>

### Test 3: Brand Consistency
**Recraft:** Brand style control — lock in colors, typography, illustration style across all generations. Better for designers maintaining brand systems. **Canva AI:** Brand Kit on Pro plan — good for template-based brand consistency, less precise than Recraft for custom vector assets.

<div class="verdict-box"><div class="verdict-label">📝 Verdict</div><p class="verdict-text"><strong>Recraft for vector-level brand precision; Canva for template-level brand consistency.</strong></p></div>
