## What Manus Does

Manus, from Beijing-based Butterfly Effect, went viral in early 2025 with demo videos of a fully autonomous agent doing real work in a cloud sandbox. It operates:

- **In the cloud** — runs in a virtual machine with its own browser, editor, and terminal
- **Autonomously** — plans a multistep approach, executes, checks, and iterates
- **On files** — produces documents, spreadsheets, presentations, and web pages
- **With tools** — web search, code execution, data extraction, file I/O
- **In parallel** — multiple tasks at once, queued and tracked
- **Continuously** — long tasks keep running after you close the tab

## 3 Key Tests

### Test 1: Research Report Assembly
**Task:** "Compile a report on solar panel prices in 2026: major brands, per-watt costs, trends, with sources and a comparison table." **Result:** Manus browsed manufacturer sites and industry reports for 25 minutes, then delivered a structured 6-page report with a working comparison spreadsheet and cited sources. Two minor errors (one outdated price, one wrong region's subsidy) needed manual correction. As a first draft that would have taken a human 3 hours: excellent ROI.

<div class="verdict-box"><div class="verdict-label">📝 Verdict</div><p class="verdict-text"><strong>Research-and-assembly is Manus's sweet spot — review the numbers.</strong></p></div>

### Test 2: Data Cleaning Task
**Task:** "Clean this messy 2,000-row CSV: normalize dates, split address columns, flag duplicates, return a summary." **Result:** Executed correctly and produced a clean dataset plus a quality report. This is where the sandbox shines — actual code execution on actual files, with the steps visible in the workspace. Comparable to what a junior analyst would deliver, in 15 minutes instead of an afternoon.

<div class="verdict-box"><div class="verdict-label">📝 Verdict</div><p class="verdict-text"><strong>Code execution on files is a genuinely differentiated capability.</strong></p></div>

### Test 3: The Hype-Check Task
**Task:** "Plan my family's two-week Japan trip: itinerary, hotels under $150/night, restaurant picks, and a budget." **Result:** Started strong — itinerary and budget spreadsheet looked reasonable. Then drift: two hotel links were broken, one restaurant had closed, and the budget double-counted transport. This is the pattern: Manus works autonomously, but its verification loop is weaker than its execution loop. For tasks where errors are acceptable and reviewable: fine. For bookings and money decisions: verify everything.

<div class="verdict-box"><div class="verdict-label">📝 Verdict</div><p class="verdict-text"><strong>Autonomy is real; reliability still trails the demo videos.</strong></p></div>
