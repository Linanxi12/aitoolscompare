## 3 Key Tests

### Test 1: General Image Quality
**Flux:** Newer architecture, hybrid diffusion-transformer, better photorealism, best text-in-image. **Leonardo:** Competent but ~0.2 points behind on general quality. Flux's model is more capable out of the box.

<div class="verdict-box"><div class="verdict-label">📝 Verdict</div><p class="verdict-text"><strong>Flux — better model, better raw output quality.</strong></p></div>

### Test 2: Specialized Production
**Task:** Generate consistent game assets — character designs, isometric tiles, environment concept art. **Leonardo:** Fine-tuned models (RPG, Isometric, Anime) produce game-ready assets with consistent style. AI Canvas inpainting/outpainting enables iterative production. **Flux:** Better base quality but requires manual fine-tuning to match Leonardo's out-of-box game asset quality.

<div class="verdict-box"><div class="verdict-label">📝 Verdict</div><p class="verdict-text"><strong>Leonardo — specialized models win for game production.</strong></p></div>

### Test 3: Flexibility
**Flux:** Apache 2.0, self-host, fine-tune, integrate. Developer's dream. **Leonardo:** Web platform only, proprietary, no self-hosting. For open-source projects and custom pipelines: Flux.

<div class="verdict-box"><div class="verdict-label">📝 Verdict</div><p class="verdict-text"><strong>Flux — open-source flexibility is a categorical advantage.</strong></p></div>
